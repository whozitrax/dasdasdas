# 💎 GRAM Bot — заявки, выплаты и рейтинг

Telegram-бот (Python 3.11+, aiogram 3, SQLAlchemy 2 async) для заявок на вывод, подтверждения выплат,
учёта заработка участников и рейтингов в группе.

## Запуск

1. Создайте бота в @BotFather, получите токен.
2. `cp .env.example .env` и заполните `BOT_TOKEN`, `PAYOUT_CHAT_ID`, `PAYOUT_THREAD_ID`.
3. **Администратор (ID 8923235001) должен один раз нажать /start у бота** — иначе бот не сможет писать ему заявки.

**Docker:** `docker compose up -d --build` (база лежит в `./data`, переживает перезапуски).

**Локально:**
```
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m bot.main
```

## Группа и тема для отчётов
- Добавьте бота в группу и сделайте администратором (право писать в темы).
- `PAYOUT_CHAT_ID` — ID группы (вида `-100…`; узнать можно, например, через @RawDataBot).
- `PAYOUT_THREAD_ID` — ID темы: это `message_thread_id` любого сообщения в нужной теме
  (или число в ссылке на сообщение: `t.me/c/<chat>/<thread>/<msg>`). Пусто — публикация в общий чат.
- Чтобы работали `/add @username` и рейтинги, отключите у бота Privacy Mode (@BotFather → Bot Settings →
  Group Privacy → Turn off) либо используйте `/add` ответом на сообщение участника.
- Не используйте «анонимного администратора» при вводе `/add` — бот проверяет личный Telegram ID.

## Команды
| Команда | Кто | Что делает |
|---|---|---|
| `/start`, `/my`, `/cancel` | все | меню, статусы своих заявок, отмена |
| `/top`, `/alltime` | все | рейтинг за сегодня (Europe/Kyiv) / за всё время |
| `/report` (ответом на сообщение в группе) | все | жалоба администратору (раздел «Модерация → Жалобы») |
| **`/panel`** | админ | **единственная команда входа в админ-панель** — всё остальное управляется кнопками |

Скрытые команды администратора (в меню Telegram не показываются, нужны для быстрой работы в группе; то же самое
доступно кнопками: «Пользователи → карточка → Начислить / Списать»): `/add @user 3.5`, `/add 123456 3.5`, ответом
`/add 3.5`; `/sub …` (коррекция); `/undo №` (или кнопка «Отменить»).

## 💜 Админ-панель (`/panel`)
Главное меню: 📩 Заявки · 📊 Статистика · 📢 Рассылка · 🛡 Модерация · 👥 Пользователи · 📜 Журнал действий · ⚙️ Настройки.
В каждом разделе есть «⬅️ Назад», в подразделах — ещё и «🏠 Главное меню».

- **Заявки** — списки по статусам, поиск, карточки с кнопками «Выплачено / Отклонить / Написать».
- **Статистика** — пользователи, заявки, выплаты, заработок, активность за 24 ч / 7 дней.
- **Рассылка** — сообщение → предпросмотр → подтверждение → результат (доставлено / не доставлено).
  Тем, кому Telegram не даёт писать, бот больше не пишет (помечаются автоматически).
- **Модерация** — антиспам (порог, удаление/мут), ссылки (разрешены / удалять / удалять и предупреждать,
  белый список вроде `t.me/nft`), жалобы, проверка прав бота в группах. По умолчанию всё выключено.
- **Пользователи** — поиск по ID / @username / имени, карточка (статус, заявки, выплаты, заработок), блокировка,
  начисление/списание, сообщение пользователю.
- **Журнал** — действия админа с временем, типом и результатом, фильтры по типу.
- **Настройки** — приём заявок вкл/выкл, лимит открытых заявок, отчёты в группу, премиум-эмодзи, обновление меню
  команд, сброс настроек (с подтверждением). Токен, ID группы и БД меняются только в `.env`.

Модерация работает в группах, где бот — администратор с правами «удалять сообщения» (и «блокировать участников» для мута),
и где отключён Privacy Mode (иначе бот видит не все сообщения).

## Как устроено
- Суммы хранятся целыми микро-GRAM (без ошибок округления), показ — `5.5`.
- Статистика: начисления (`accruals`) и выплаты (`payouts`) независимы — выплата **не уменьшает** рейтинг заработка.
  Баланс не ведётся: бот не угадывает суммы, админ вводит фактическую выплату вручную.
- Выплата: `UPDATE … WHERE status='pending'` + `UNIQUE(payouts.request_id)` — повторное нажатие/параллельные клики
  не создают дубль. Начисление: `UNIQUE(chat_id, message_id)` команды.
- Один подарок не может иметь две активные заявки (частичный уникальный индекс); после отклонения можно подать снова.
- Основной идентификатор — Telegram ID; username хранится только для поиска и отображения.
- Все действия админа пишутся в `admin_log` (и показываются в «Журнале действий»).
- Настройки панели, флаги пользователей и жалобы лежат в новых таблицах `bot_settings`, `user_flags`, `complaints`
  (создаются автоматически; существующие таблицы и данные не меняются, миграция не нужна).
- PostgreSQL: `pip install asyncpg`, `DATABASE_URL=postgresql+asyncpg://user:pass@host/db`. Таблицы создаются автоматически
  (для будущих изменений схемы подключите Alembic).

## Допущения
- Фиолетовый цвет кнопки Bot API не поддерживает — используется стандартная кнопка с 💜 (Mini App не делался).
- Формат ссылки на подарок: `https://t.me/nft/Имя-123` (и `t.me/gift/…`). Меняется в `utils.py` (`_GIFT_RE`).
- Адрес GRAM проверяется как TON-адрес (friendly 48 символов с контрольной суммой или raw `0:hex`).
  Если ваш способ выплаты использует другой формат — `WALLET_VALIDATION=none`.
- Скриншоты принимаются как фото (до 10); файлы-документы бот попросит прислать как фото.
- Черновик заявки хранится в памяти: если бот перезапустится на середине заполнения, пользователь начнёт заново.
  Поданные заявки, фото (file_id), суммы и история сохраняются в БД.
- Картинки: `assets/welcome.png` (приветствие) и `assets/payout.png` (отчёт в группу) — взяты из ваших файлов,
  замените на нужные при желании (на текущей написано «ВЫПЛАЧЕНО», а не PAYMENT COMPLETED).
- Сообщения пользователя вне заявки пересылаются администратору с кнопкой «Ответить».

## Премиум-эмодзи
- Обычные эмодзи в текстах бота автоматически заменяются на премиум по таблице `UI_MAP` в `bot/emoji.py`
  (💎 🎁 🔗 ✅ ❌ 🔔 📌 💰 🏆 🥇🥈🥉 📊 💬 ⚠️ и др.). Пользователи без Premium видят обычные.
- Все присланные ID лежат в `CATALOG` (имя → эмодзи, ID); для ручной вставки: `pe("fire")`.
- Отключить: `PREMIUM_EMOJI=false`. Если Telegram отклонит эмодзи, бот сам повторит отправку без них.
- Ограничение Telegram: кастомные эмодзи в сообщениях ботов работают, если у бота есть дополнительные
  username, купленные на Fragment; иначе все увидят обычные эмодзи.
- Админ может прислать боту в личку любое сообщение с премиум-эмодзи — бот ответит их ID.
